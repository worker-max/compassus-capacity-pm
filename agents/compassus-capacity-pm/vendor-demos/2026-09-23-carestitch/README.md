## Bottom line

**Hold at Conditional.** CareStitch is a strong scheduler workspace built by home health operators, with the best coordination tooling in the field:
- capacity in points by clinician and day, on a map;
- territories drawn as polygons;
- a staffing-request workflow with priority groups and response logs;
- care-team chat attached to every patient;
- offline-first mobile.

It advises and does not decide. Every assignment is manual. HCHB integration is a read-only beta that has never run in production, and the demo didn't cover it. There is no home health logic (orders, auth, LUPA, windows), and patient engagement is roadmap. Advance only if the offered follow-up shows a dated HCHB plan and working automation.
