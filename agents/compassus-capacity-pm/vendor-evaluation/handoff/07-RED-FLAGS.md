# 07 · Red-flag catalogue

One row per pattern. Ids are never renumbered. A flag in a brief cites its id, so it is a pattern
match and not an opinion. Severity: **STOP-CHECK** (resolved before advancing), **Watch** (goes on
the demo agenda), **Note** (shapes a mark or a read).

A pattern is added only with a real phrasing from a real return. Propose additions to the PM; do not
edit this file.
