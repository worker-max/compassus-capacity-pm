# Working rules for this repo

## PDFs and shareable documents
- **Always show the HTML version for review first.** Publish or share the HTML draft and wait for
  the owner's edits or approval before generating any PDF. No PDF is created until the HTML is signed off.
- Shareable documents use a plain internal-memo style: Arial/Liberation Sans, white page, standard
  shaded tables, plain wording. No display serifs, italic accent words, monospace eyebrows or dot ratings.
- Strip PDF metadata (author, creator, producer) and keep WorkforceWave out of anything shared with Compassus.

## Vendor evaluation (owner rules, 29 Sep 2026)
- **Neutral comparisons.** Cross-vendor documents compare; they do not rank or recommend. List vendors
  alphabetically, describe each factually, and never call one "strongest" or "best". The team decides.
- **Two sources, always labelled.** Use the demo call *and* the vendor's RFP (questionnaire) return, which
  carries clarifications. Mark return-only claims "RFP" (or "RFP return only") and keep them distinct from
  what was shown in the demo. Where the two disagree, show both. Returns and the formal scorecard live in
  Drive `VendorScorecard Rubric 9.11.26 Copy.xlsx` (one tab per vendor, plus `Scorecard`).
- **Score movement is marked, not applied.** Show the formal RFP score, then mark where demo evidence
  supports a change (▲ / ▼ / ? unverified / = matched) using the scorecard's own rubric. The formal
  score stays unchanged until the team re-scores.
- **Screens must read without zooming.** Full-width screenshots, one per printed page; phones three across;
  zoomed crops of key panels (see `.claude/skills/vendor-demo-breakdown`).
- **Flows the team knows.** Vendor overlays sit on our own flows; the four-vendor view uses the Flow 1
  Start of Care steps with one lane per vendor.
- **Privacy.** Drop any frame showing another customer's data (names, patients) and note it.
